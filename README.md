
# blomjensen.github.io

Personal portfolio site for Bjorn Blom-Jensen, built with React and Vite.

## Development

Install dependencies:

```bash
npm install
```

Start the local dev server:

```bash
npm run dev
```

## Production build

Create the production build:

```bash
npm run build
```

## Deploy

Push to `main` to deploy via the GitHub Pages workflow.
