
# Bjørn Blom-Jensen Portfolio

Personal portfolio site for Bjørn Blom-Jensen, newly graduated landscape architect from AHO.

Local workspace:

```bash
/Users/bjornblomjensen/Developer/bjorn-portfolio
```

Built with React and Vite.

## Development

Install dependencies:

```bash
npm install
```

Start the local dev server:

```bash
npm run dev
```

## Production build

Create the production build:

```bash
npm run build
```

## Deploy

Push to `main` to deploy via the GitHub Pages workflow.

GitHub Pages is the canonical deployment path for this repo. `netlify.toml` is present as a secondary or legacy deployment config and should be reviewed before relying on Netlify.
